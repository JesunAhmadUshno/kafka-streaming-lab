# Security policy

Report a vulnerability privately through GitHub's "Report a
vulnerability" button on this repository's Security tab. Please do not
open a public issue for it. You will get a reply within 7 days.

Scope: the code in this repository. The Kafka broker runs in Docker on
one private lab machine, bound to 127.0.0.1, and is not exposed to the
internet. No credential is stored in this repository.
